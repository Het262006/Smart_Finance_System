# Expense Tracker Web App

A simple web-based finance application to track income, expenses, and investments.
This project helps users manage their daily financial activities in one place.

---

## Features

* User registration and login
* Dashboard to view financial summary
* Add, edit, and delete transactions
* Track income and expenses
* Investment tracking
* Basic charts for analysis

---

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Local Server: XAMPP

## How to Run Locally

1. Install XAMPP
2. Start Apache and MySQL
3. Copy the project folder to:

   ```
   C:\xampp\htdocs\
   ```
4. Open phpMyAdmin and create a database (e.g., `finance_tracker`)
5. Import your `.sql` file into the database
6. Update database connection in:

   ```
   includes/db.php
   ```
7. Open in browser:

   ```
   http://localhost/expense-tracker
   ```
